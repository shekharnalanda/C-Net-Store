# C-Net Store

Multi-vendor e-commerce, grocery and food-delivery platform launching in Bihar Sharif.

- Website: https://cnetstore.mciedu.com
- Backend: Laravel 12 REST API and Super Admin
- Apps: Flutter Customer, Seller and Delivery Partner applications
- Payments: Online only; Cash on Delivery is disabled

See `docs/PROJECT_SCOPE.md` and `docs/ARCHITECTURE.md` for the approved scope and repository structure.
